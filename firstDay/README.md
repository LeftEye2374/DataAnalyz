# Titanic Survival Prediction — первый ML-проект

Учебный проект: предсказание выживаемости пассажиров Титаника на основе классических алгоритмов машинного обучения. Первый проект в портфолио на пути к позиции ML Engineer.

## Датасет

Классический датасет [Titanic — Machine Learning from Disaster](https://www.kaggle.com/c/titanic) с Kaggle.

Файлы: `train.csv`, `test.csv`, `gender_submission.csv`.

## Стек

- Python 3.12
- pandas, NumPy — обработка данных
- matplotlib — визуализация
- scikit-learn — Logistic Regression, Random Forest, метрики
- CatBoost — градиентный бустинг
- Jupyter Notebook

## Пайплайн проекта

### 1. Разведочный анализ данных (EDA)

- Проверка структуры данных (`.info()`, `.describe()`, `.isnull().sum()`).
- Визуализация распределения возраста пассажиров (гистограмма).
- Анализ выживаемости по классу билета (`Pclass`) и по полу (`Sex`).

**Инсайты из EDA:**
- Пассажиры первого класса выживали значительно чаще, чем третьего.
- Возраст имеет заметное количество пропусков, требующих обработки перед обучением модели.

### 2. Предобработка данных

- Заполнение пропусков в `Age` медианным значением.
- Заполнение пропусков в `Embarked` модой (наиболее частым значением).
- Удаление колонок с высокой долей пропусков или не несущих предсказательной ценности в baseline-модели: `Cabin`, `Name`, `Ticket`, `PassengerId`.
- Кодирование категориальных признаков: `Sex` — бинарное кодирование (male/female → 0/1), `Embarked` — one-hot encoding (`pd.get_dummies`).

### 3. Обучение моделей

Данные разбиты на train/validation (80/20, `random_state=42`). Обучены и сравнены три модели:

| Модель | Accuracy | Precision | Recall |
|---|---|---|---|
| Logistic Regression | 0.810 | 0.786 | 0.743 |
| Random Forest | 0.799 | 0.764 | 0.743 |
| CatBoost | 0.816 | 0.836 | 0.689 |

### 4. Кросс-валидация (CatBoost)

Для проверки устойчивости результата проведена 5-fold кросс-валидация на лучшей по accuracy модели:

Разброс между фолдами (~6 п.п.) в пределах нормы для датасета такого размера — результат не является случайностью одного удачного разбиения данных.

## Выводы

- **Более сложная модель не всегда даёт прирост качества.** Random Forest без тюнинга гиперпараметров показал результат немного хуже, чем простая логистическая регрессия — на небольшом и относительно "линейном" датасете это ожидаемо.
- **CatBoost показал лучший баланс accuracy/precision**, но заметно уступил по recall (0.689 против 0.743 у остальных моделей). Модель стала консервативнее: реже ошибочно предсказывает "выжил", но за счёт этого чаще пропускает реально выживших пассажиров.
- Выбор оптимальной модели в реальной задаче зависел бы от цены ошибки каждого типа — что критичнее для бизнес-задачи: ложные срабатывания или пропущенные положительные случаи. Для Титаника это учебный вопрос, но сам принцип применим к любой задаче классификации (например, детекция мошенничества, медицинская диагностика).
